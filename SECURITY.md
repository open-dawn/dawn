# Security Policy

## Supported versions

DAWN is in alpha. Security fixes are provided for:

* the latest published [GitHub Release](https://github.com/open-dawn/dawn/releases)
* the current `main` branch

Older tags are not maintained.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Report it in private, by either channel:

* [GitHub private vulnerability report](https://github.com/open-dawn/dawn/security/advisories/new)
* email to [security@opendawn.app](mailto:security@opendawn.app)

Include what is affected, how to reproduce the problem, and the impact you expect. The maintainers will acknowledge the report and coordinate a fix before any public disclosure.

Please allow a reasonable time for a response before disclosing the issue publicly.
